## 产品简介

YSHOP 意象宠物管理系统是一款专为中小型宠物店打造的经营管理系统，面向宠物门店、宠物服务中心、宠物洗护寄养俱乐部等宠物服务类经营主体量身设计。

系统全面适配宠物门店数字化经营全流程，帮助门店告别社群接单、手写台账等传统低效模式，覆盖服务项目上架、后台一站式收银、笼位状态管控、服务日历提醒、订单管理、商品库存、会员与宠物档案、企业组织等核心环节，实现业务线上标准化统一管控。

**定位：** 收银 → 寄养 → 笼位 → 日历 → 订单 → 库存 → 会员 → 宠物档案

**适用：** 宠物门店（商品零售、洗护美容等综合服务） / 宠物服务中心 / 宠物洗护寄养俱乐部 / 其他宠物服务类经营主体

**核心能力：** 一站式收银台 · 确认结账多支付 · 二维矩阵笼位管控 · 寄养登记与退房 · 服务日历提醒 · 订单全生命周期 · 商品/服务/寄养上架 · 采购入库 · 宠物档案与复购建议 · 会员等级折扣 · 企业组织权限

## 功能详解

### 1. 一站式收银台

集成化操作界面即可完成全部日常收银工作，支持扫码收款、会员充值、商品结算、服务核销、寄养登记收费。

- **会员信息面板：** 展示头像、姓名、手机号、余额、累计消费、会员等级与折扣、宠物数量；支持「会员概况 / 宠物信息 / 订单记录」切换
- **扫码录入：** 支持商品、服务、条形码扫码枪录入，输入后按 Enter 键即可快速加入购物清单
- **混合结算：** 商品、服务、寄养项目可在同一购物清单合并结算，可改零售价、折扣率、折后价与数量，自动计算小计与应付
- **寄养提醒：** 寄养类商品需设置寄养信息，界面有明确提示，避免漏填
- **挂单管理：** 支持待结算挂单与挂单调取，营业高峰可先挂单后结算
- **快捷操作：** 选购、挂单、创建会员、会员充值一键可达

### 2. 确认结账

收银台「去结账」后弹出确认结账弹窗，完成支付闭环。

- **会员摘要：** 展示当前会员与账户余额
- **选择宠物：** 为本次消费关联宠物（如「小狗」）
- **支付方式：** 支持微信、支付宝、现金等多种方式切换
- **金额处理：** 应付金额高亮展示，可填优惠金额，支持一键抹零
- **确认支付：** 一键确认支付并展示实付金额

### 3. 二维矩阵笼位状态管控

按「日期 × 笼位」直观展示所有寄养笼位的实时使用情况，通过颜色标记区分状态，系统自动同步更新。

- **KPI 卡片：** 总笼位数、今日空闲、今日入住、预约总数一目了然
- **状态图例：** 空闲 / 入住 / 在住 / 退房 / 今日 / 已过，颜色区分清晰
- **笼位档案：** 自定义笼位分类（如猫笼、狗笼），记录尺寸规格、最大承重、适用物种与排序权重
- **批量添加：** 选择分类、名称后缀、起止序号，系统自动计算生成数量，支持适用物种标签
- **实时同步：** 寄养登记选择笼位后自动标记占用，寄养结束自动释放

### 4. 寄养登记与退房

在收银台或寄养看板即可完成寄养登记与退房全流程，收费与笼位占用一次操作同步完成。

- **信息完整：** 登记寄养宠物、入住时间与预计离店时间，系统自动计算寄养天数
- **笼位分配：** 登记时直接选择笼位，自动关联二维矩阵状态
- **详情弹窗：** 展示订单、状态（寄养中）、品种、笼位、入住/预计离开、天数、主人与电话
- **确认退房：** 填写实际离店时间后一键确定退房，释放笼位
- **贴心备注：** 支持记录饮食、用药等注意事项（如食物过敏、需要每天喂药）

### 5. 服务日历提醒

按天 / 周 / 月查看服务与预约日程，状态分明，逾期醒目提醒。

- **迷你月历：** 左侧快速切换日期，定位今日
- **提醒状态：** 待处理（橙）、已联系（绿）、已完成（灰）、已逾期（红）
- **日视图时间轴：** 按小时展示服务事项（如「洗澡 · 兔子1号」）
- **逾期横幅：** 顶部醒目提示已逾期任务，避免漏服/漏约

### 6. 订单管理

完整记录门店消费订单，支持状态筛选与多条件检索。

- **状态页签：** 全部 / 已完成 / 已退款快速切换
- **条件筛选：** 按单号、客户姓名、支付方式搜索与刷新
- **订单明细：** 展示商品/服务图标、名称、类型标签（如寄养）、单价 × 数量
- **金额明细：** 应付金额、订单总额、优惠、实付/余额抵扣分区展示
- **创建信息：** 创建时间与操作人留痕；支持取消订单等操作

### 7. 轻量化商品与库存管理

统一管理商品、服务、寄养三类项目，并内置采购入库、出库、盘库与时序追溯。

- **三类项目：** 商品 / 服务 / 寄养统一上架，出售中 / 已售罄页签切换
- **分类侧栏：** 宠物服务、寄养服务、宠物用品、宠物药品、宠物粮食、宠物玩具等分类筛选
- **规格管理：** 支持单规格与多规格，可分别设置售价、成本、库存、产品编号与条码
- **库存预警：** 可按商品启动库存预警并设置预警数量
- **采购入库：** 单据编号、供应商、入库时间、审核状态筛选；支持新增、审核/反审核、打印
- **新增入库：** 左侧选品（条码/搜索）填单价与数量，右侧填供应商与入库日期，自动汇总总金额
- **记录溯源：** 入库时序、出库时序完整留痕，每一笔库存变动都有据可查

### 8. 宠物档案全生命周期

详细记录客户与宠物的核心信息，建立覆盖宠物服务全生命周期的档案体系。

- **列表检索：** 按宠物名、主人筛选，支持新增宠物档案
- **档案详情：** 宠物名、种类/性别标签、品种、生日、绝育、体重、花色
- **主人卡片：** 姓名、电话、累计消费金额
- **复购建议：** 可新增维护复购建议，促进二次消费
- **服务记录：** 时间线展示历史服务（如打针服务已完成及金额）

### 9. 全维度会员体系

支持自定义会员等级，为各等级配置专属折扣权益与充值营销。

- **等级自定义：** 可自由创建会员等级（如普通、白银、黄金、铂金），配置等级图标与背景颜色
- **折扣权益：** 按等级设置折扣率（如 100 / 90 / 80 / 70），收银结算自动生效
- **排序与状态：** 排序权重控制展示顺序，状态支持正常/禁用
- **充值营销：** 充值活动支持「充值赠送」规则配置，吸引会员预存
- **余额管理：** 充值订单与余额记录独立可查，每一笔资金变动清晰透明

### 10. 企业组织与员工管理

支持多级组织树与员工全生命周期管理，适配连锁或多门店协同。

- **组织树：** 按公司 / 分公司 / 部门层级展示，可搜索定位
- **员工筛选：** 按用户名称、手机号码、状态、创建时间筛选
- **账号管理：** 新增、导入、导出；状态开关一键启停
- **权限体系：** 角色管理、部门管理、岗位管理、通知管理联动
